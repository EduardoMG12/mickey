# Code of conduct

Mickey follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, criticise code and not
people, and remember that many contributors are learning (this project is a
learning project first). Harassment, insults and personal attacks are not
welcome in issues, pull requests or anywhere else the project lives.

To report a problem with someone's behaviour, use the repository's private
reporting (*Security → Report a vulnerability*, saying it is a conduct
report). Reports are read by the maintainer only and kept private.
